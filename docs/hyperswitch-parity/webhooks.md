## Implementation disposition
Re-verified 2026-11-20 against current `include/app/handlers/webhooks.cppm`. One line per original `## Not ported` bullet.

- Connector webhook decode + business-logic effects — SUBSTITUTED — `decode_event()` classifies payments/refunds/disputes/mandates/payouts/network_token by payload markers and extracts object ids (`webhooks.cppm:726-781`); real connector decoders and state-mutating payment/refund/dispute effects still absent.
- Merchant connector account validation (3DS/UAS/UCS) — SUBSTITUTED — `validate_connector_account()` resolves MCA via `repository().list_merchant_connectors()` with profile match, `connector_router().select_checked()` fallback, NOT_FOUND on mismatch (`webhooks.cppm:643-679`, called `:883`); 3DS execution path / UAS-vs-Direct / UCS path selection still absent.
- Router-managed source verification (mTLS/IP/connector signature/policy) — SUBSTITUTED — `verify_webhook_source()` does HMAC over `x-webhook-signature`, IP allow-list via `config_store()`, mTLS `x-client-cert`, connector `webhook_source_verify` call, and `policy_default` when nothing configured (`webhooks.cppm:566-638`, secrets `:550-560`); supersedes the old HMAC-only check.
- `IncomingWebhookEventMetadata` / event logging — SUBSTITUTED — typed `IncomingWebhookResponse` envelope (`webhooks.cppm:36-85`, populated `:907-925`) published via `events().publish("webhook.incoming...")` (`:930-935`) with `webhook_delivery().enqueue()` (`:937-940`); carries connector, object ids, tracker, serialized request.
- `api_locking` / lock-action + `server_wrap` state — SUBSTITUTED — `locks().acquire(lock_key, 30, "webhooks")` with body-hash dedupe key and release on duplicate/success (`webhooks.cppm:889-897`, `:901`, `:942`); `server_wrap` request-scoped state plumbing not replicated.
- Typed auth variants (path merchant/profile, NoAuth) — SUBSTITUTED — `authorize_operation()` resolves a per-operation rule from `auth_rules().rule_for()` and overlays path-derived merchant/profile into `AuthContextBuilder` (`:531-548`); NO_AUTH pass-through, network-token `no_auth` (`:872-875`); flat `WEBHOOK_WRITE` removed.
- Webhook-events query/retry API (list attempts, retry) — DEFERRED — no handlers in `webhooks.cppm`; only outbound `webhook_delivery().enqueue()` (`:939`), no list/retry routes.
- Feature-gated routes (revenue-recovery, frm fulfillment) — DEFERRED — no routes in `install()` (`webhooks.cppm:313-439`); upstream feature-gated recovery/frm routes remain absent.
- Labeled `WEBHOOK_INCOMING_COUNT` w/ merchant dimensions — SUBSTITUTED — `record_metrics()` increments flow/counter, `WEBHOOK_INCOMING_COUNT` and a merchant-dimension counter keyed by a hashed tag (`webhooks.cppm:834-849`); dimension encoded as hash suffix, not native labels.
