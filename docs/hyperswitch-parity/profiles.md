## Not ported (external infrastructure only)
Every remaining substitute is an in-process stand-in for infrastructure that does not exist in this build; no upstream-observable behavior is left unimplemented.

- Master-key decryption and the real key store (`core/admin.rs:4128-4133,4906-4912`): local repository plaintext + `config_store().get_value("keys","master")` (`cppm:1187-1197`).
- Live outbound destination DNS/network resolver (`outbound_destination::validate_destination`, `core/admin.rs:4232-4240`): local scheme + bypass-host check (`cppm:1118-1140`).
- Live decision engine / dimension state (`core/admin.rs:4706-4719`): local config flag + `decision_engine().evaluate` + routing-config repository lookup (`cppm:1164-1183`).
- Key-manager encryption of `webhook_details`/`network_tokenization_credentials`/`card_testing_secret_key` (`core/admin.rs:4292-4313,4331-4351`): local store keeps the serde value directly; the C++ `ProfileResponse` DTO has no encrypted-secret fields.
- Compile-time scaffolding (`#[instrument]`, `Flow::*`, `#[cfg(olap|v1|v2)]`, `api::server_wrap`, `LockAction::NotApplicable`): C++ records upstream flow names and counters (`cppm:81-83,111-113,157-159,185-187,209-211,239-241,281-283,327-329`) and mounts v1/v2 scopes at runtime (`cppm:339-478`).
- `admin::connector_list_profile` (`app.rs:2802`) is intentionally not registered here; it belongs to `admin.cppm:1291-1329,1707-1715`. `profiles::payment_connector_list_profile` (`profiles.rs:564-597`) has no upstream route, so no C++ route is retained — see Shared contract requests.
