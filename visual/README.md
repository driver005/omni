# visual

Frontend copied from the Ghost monorepo. Contains only `apps/`, `koenig/`, `packages/`,
`contracts/` and the root pnpm configuration — the Ghost `ghost/` backend and `e2e/` are
deliberately absent.

Do not add request logic here. Call the Rust SDK through
`packages/congelado-sdk/src/index.ts`, which wraps the WASM glue generated by `make sdk-wasm`.

```sh
pnpm install
pnpm dev
```
