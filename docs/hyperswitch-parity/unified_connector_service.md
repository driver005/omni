## Local Redis substitute contract
The C++ handler ports the two upstream endpoint functions verbatim but backs the Redis counters with the injected `core::cache` (external infra, substituted locally by decision).

- **Two stores**: `state.store` (tenant) → cache namespace `unified_connector_service.redis.tenant:`, `state.global_store` (global/shadow) → `unified_connector_service.redis.global:` (`unified_connector_service.cppm:403-413`; upstream `kill_switch.rs:545-552,915-924`).
- **Keys and fields**: Redis key `ucs_kill_switch_<scope>` / `ucs_shadow_killed` (`:394-401`; `kill_switch.rs:47-50, consts.rs:399,407`); hash fields `counter` and `counter_connector_decline` are the two JSON members of the single cache entry (`:427-449`; `kill_switch.rs:23,29`). A missing key/field reads as 0 (`:459-465`; `kill_switch.rs:192-195`).
- **TTL**: primary 7 days, shadow 24 hours (`:34-35,498-507`; `consts.rs:405,409`); carried by the cache entry expiry. Expiry is honoured on read and on `DEL` via `CacheQuerySpec::matches` (`:415-425,512-522`).
- **Increment**: `write_hash_counter`/`increment_counter` port `HINCRBY` + best-effort `EXPIRE` (`:471-507`; `kill_switch.rs:435-521`), feeding the counters that these read/reset endpoints expose.
- **DELETE**: `KeyDeleted` → `StatusOk` (empty body); `KeyNotDeleted` → `GenericNotFoundError("No UCS kill switch counter found for scope <rollout_scope>")` (`:196-212`; `kill_switch.rs:561-576`). A closed cache is the local analog of `get_redis_conn`/`delete_key` failure → `InternalServerError` (`:86-98,182-190`; `kill_switch.rs:553-559,604-608`).
- **Config source**: comparison-service fallback and Superposition source check are local config rows (`config_store`/`superposition`/`repository`) with upstream's decision order preserved (`:580-633`; `kill_switch.rs:928-965`).
