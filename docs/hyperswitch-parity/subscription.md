## Shared contract requests

This handler does **not** consult the registry for subscription auth (it implements upstream `auth_type`/`check_sdk_auth_and_get_auth` semantics locally at `:1100-1172`). Please leave the registry entries as-is; no change is required for this module to be MATCH. If a future refactor routes these ops back through `authorize_route`, the registry must add `HEADER_MERCHANT`/`SDK`/`CLIENT_SECRET` variants with `allow_connected=false`/`allow_platform=false` and `PROFILE_SUBSCRIPTION_READ/WRITE` permissions.

If shared DTO normalization is added, the encoders can be replaced with typed serialization with no wire change. No shared change is required for MATCH.
- Billing processor / payments microservice / invoice table are external upstream services with no in-process C++ implementation; the sanctioned local substitutes (ConnectorRouter, payment repository, config_store, process_trackers, events) are used throughout. No shared change requested.
