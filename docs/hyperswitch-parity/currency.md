## Not ported
Historical gap snapshot (superseded by disposition below; line cites are from the earlier report revision).
- Live forex provider fetch and config-driven expiry: upstream `get_forex_rates(&state, conf.forex_api.data_expiration_delay_in_seconds)` (`core/currency.rs:18-20`, provider config read at `:59`). C++ substitutes a deterministic seeded table with hardcoded 300 s TTL (`currency.cppm:42-57,230-246`).
- Analytics retry helper `get_forex_exchange_rates` with `DEFAULT_ANALYTICS_FOREX_RETRY_ATTEMPTS`, retryable-error classification and backoff (`core/currency.rs:56-101`). No C++ analogue.
- Distributed cache/Redis locking semantics behind `get_forex_rates`/`convert_currency` (lock acquisition errors listed at `core/currency.rs:72-83`). C++ uses a single local in-memory cache entry (`currency.cppm:42-56`).
- Full supported-currency set and canonical minor-unit exponents from the `currency_conversion` crate (`core/currency.rs:3,38-43`). C++ hardcodes only USD/EUR/GBP/INR/JPY/CAD/AUD/CHF (`currency.cppm:249-262`).
- `MinorUnit::get_amount_as_i64` integer minor-unit handling (`routes/currency.rs:42,53`; `api_models/currency.rs:7`). C++ parses to `double` via `std::stod` (`currency.cppm:134-144`), risking precision loss on large amounts.
- `server_wrap` middleware: `Flow::RetrieveForexFlow` instrumentation, `LockAction::NotApplicable`, and the dashboard `DashboardNoPermissionAuth` path (`routes/currency.rs:12-13,24-30,41,63-69`). C++ has only manual API-key authorization and hand-incremented metrics (`currency.cppm:30-37,69-70,80-87,164-165`).
- Upstream's exhaustive error taxonomy: `ForexCacheError` variants (lock/cache/provider failures) collapsing to `InternalServerError` (`core/currency.rs:45-52,71-83`). C++ never emits `InternalServerError` for these routes (`currency.cppm:59-66,96-103,119-143`).

## Implementation disposition
- Live forex provider fetch and config-driven expiry — SUBSTITUTED — TTL now read from `config_store().get_value("forex_api","data_expiration_delay_in_seconds")` with default 300 s and cap 86400 (`currency.cppm:246-266`); deterministic seed used as the fetch result (`currency.cppm:297-300,325-341`). No live provider/credentials exist locally: provider fetch remains an external-dependency STUB.
- Analytics retry helper `get_forex_exchange_rates` — SUBSTITUTED — `load_rates()` 3-attempt loop with `kMaxAttempts=3` (`DEFAULT_ANALYTICS_FOREX_RETRY_ATTEMPTS`, `currency.cppm:276`), retryable lock/write paths (`currency.cppm:289-311`), and attempt-based backoff recorded as metric data rather than sleep (`currency.cppm:318-322`).
- Distributed cache/Redis locking semantics — SUBSTITUTED — cache get/put of `"currency.forex_rates"` (`currency.cppm:279-304`) and local `app_locking` acquire/release of `"forex.rates.refresh"` (`currency.cppm:289,307,311`). Distributed Redis backend itself is an external dependency, not implemented.
- Full supported-currency set and canonical minor-unit exponents — SUBSTITUTED — `minor_unit_exponent()` covers the canonical 0/2/3 ISO exponents (`currency.cppm:370-383`) and is applied in conversion (`currency.cppm:390-395`); rate factors still limited to 8 seeded currencies (`currency.cppm:386-400`). Full set requires provider data (external dependency).
- `MinorUnit::get_amount_as_i64` integer minor-unit handling — IMPLEMENTED — `parse_minor_i64` uses `std::from_chars` into `std::int64_t` with full-consumption and non-negative checks (`currency.cppm:351-363`), used at `currency.cppm:127`; no `std::stod`/`double` amount parse.
- `server_wrap` middleware / dashboard auth path — SUBSTITUTED — two declarative `auth_rules().rule_for(...)` calls model the API-key OR dashboard path (`currency.cppm:34-43,71-80`); `record_flow("RetrieveForexFlow")` + counters manually (`currency.cppm:60-61,163-164`). Literal `server_wrap` and `DashboardNoPermissionAuth` not present.
- Upstream exhaustive error taxonomy — IMPLEMENTED — `internal_server_error()` sets kind name `InternalServerError` (`currency.cppm:235-243`) and is emitted on convert rates failure (`currency.cppm:120`) and retry exhaustion (`currency.cppm:314`); `invalid_request_data()` sets `InvalidRequestData` (`currency.cppm:224-232`) for unsupported currencies/non-numeric amounts (`currency.cppm:130-136`).
