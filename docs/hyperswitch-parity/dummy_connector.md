## Not ported

- `auth::NoAuth` semantics and missing `Host("localhost")` guard.
- Redis persistence with `authorize_ttl`/`payment_ttl`/`refund_ttl` and attempt-key deletion.
- `process_payment_attempt` / 3DS state machine, connector enum and per-PM pages/CSS.
- Real generated `dummy_attempt`/`dummy_ref` ids (and the `pay_` payment id).
- Refund eligibility (`eligible_amount` first, then status) and `eligible_amount` decrement.
- HTML authorize/expired pages and real return URL / redirect semantics.
- Config-driven mock latency with delay+tolerance.
- Typed DTOs & validation for requests and persisted values.
- `server_wrap` flow instrumentation / `LockAction::NotApplicable`.
- Typed `DummyConnectorErrors` variants and the upstream error envelope.
- v1/v2 surface divergence.

## Shared contract requests
These need changes outside this module's allowed edit scope and are recorded for the owning lanes:
1. **Router-level v1/v2 gate** — `routes.cppm`/install site must expose a version dimension so `/dummy-connector` installs only `POST /payment` under v2 (`app.rs:890-904`); the handler cannot self-gate without editing the router.
2. **First-class `state.base_url`** — authorize return URLs and redirect URLs use upstream `state.base_url` (`core.rs:69,411`); C++ reads a config key `dummy_connector/base_url` (`cppm:1263-1266`). Expose the server base URL on `AppContext` so this and other modules stop guessing.
3. **Typed `settings::DummyConnector`** — upstream uses typed config (`crates/router/src/configs/settings.rs:768-787`); C++ reads generic `ConfigStore` keys under namespace `dummy_connector` (`cppm:1244-1261`). A typed config binding would cover `assets_base_url`, `default_return_url`, `slack_invite_url`, `discord_invite_url`, all TTLs and all duration/tolerance fields.
4. **Compile-time `external_access_dc` feature** — upstream toggles the Host guard at compile time (`app.rs:858,894`); C++ uses runtime config (`cppm:1231-1234`). A build flag exposed to handlers would remove this substitute.
5. **Redis-backed cache service** — the in-process `core::cache::Cache` preserves keys/values/TTLs but is not durable or shared across instances; a Redis service behind the existing cache facade would close the last external-infra substitute.
6. **Shared typed error envelope / DTO partition** — `DcError` and the request/response DTOs are local (`cppm:31-158,153-158`); an `app_dto` partition and a shared `ApiErrorResponse`-shaped error type would let other modules reuse the upstream wire envelope (`api_models/errors/types.rs:37-58`).
