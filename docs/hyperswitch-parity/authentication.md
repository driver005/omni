## Shared contract requests
- `include/app/auth/registry.cppm:42` records `authentication_create` with `allow_connected = true, allow_platform = true`, but upstream `routes/authentication.rs:40-43` declares `ApiKeyAuth { allow_connected_scope_operation: false, allow_platform_self_operation: false }`. Please change the registry row to `false, false` so other callers resolve the correct flags; this handler applies the correct values via an inline rule at `authentication.cppm:579-595` in the meantime.
- The shared DTO `include/app/dto/authentication.cppm` models several upstream externally-tagged enums as flat C++ enums (`EligibilityResponseParams`, `AuthenticationSdkNextAction`, `AuthenticationEligibilityCheckResponseData`, `AuthenticationSessionToken`). Those wire shapes are emitted directly by `JsonObject` in this handler (`authentication.cppm:213-255`, `:911`, `:947-951`, `:1077`). If the DTOs are generalized to tagged variants, this handler can switch to them without changing routes or semantics.
- The local `app::store` `AuthenticationRecord` carries only 8 columns (`include/app/store/identity_records.cppm:137-170`). A wider authentication table (or a reflected cache entity) would let `AuthenticationRecordData` move from the cache JSON substitute to first-class persistence; no behavioral change would be required.
