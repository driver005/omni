## Not ported
- **`auth::NoAuth` semantics.** Upstream deliberately unauthenticated (`dummy_connector.rs:32,58,79,101,124,146`); C++ requires token + `PAYMENT_*`/`REFUND_WRITE` permissions (`cppm:27-30,73-76,122-125,162-165,209-212,265-268`). Host guard `Host("localhost")` (`app.rs:857-862`) absent.
- **Redis persistence + TTLs.** `store_data_in_redis` with `authorize_ttl`, `payment_ttl`, `refund_ttl` and attempt-key deletion (`core.rs:27-40,106-126,182-205`); C++ only in-process cache, no TTL/expiry (`cppm:51-60,145-147,254-255`).
- **`process_payment_attempt` / 3DS state machine.** Upstream builds `DummyConnectorPaymentData` with `next_action`, `DummyConnectors` (phonypay/fauxpay/pretendpay/stripe/adyen/checkout/paypal, `types.rs:28-42`) and payment-method-specific flow/CSS pages (`core.rs:23-25,67-76`; `utils.rs`; `consts.rs:3-5`). C++ stores raw body and hardcodes `next_action:null` (`cppm:145-152`).
- **Real generated IDs.** Upstream `generate_id_with_default_len("dummy_attempt")` / `"dummy_ref"` (`types.rs:81`, `core.rs:179`; `consts.rs:1-2`). C++ uses `std::hash` → `att_`/`pay_`/`rf_` (`cppm:142-144,249`).
- **Refund eligibility logic.** `is_eligible_for_refund` checks `eligible_amount >= amount` and `status == Succeeded` with typed errors (`types.rs:301-315`, `core.rs:177`); C++ only checks status string and echoes the entire body as `refund_amount` (`cppm:242-253`); no `eligible_amount` decrement (`core.rs:180`).
- **HTML authorize / expired pages & return URL.** `get_authorize_page` / `get_expired_page` served as `FileData(TEXT_HTML)` with `{base}/dummy-connector/complete/{attempt_id}` return URL (`core.rs:67-84`); C++ returns JSON tokens (`cppm:53-64`). Completion redirection uses real `return_url` or configured default (`core.rs:127-152`); C++ uses payment_id (`cppm:105-113`).
- **Config-driven mock latency.** `tokio_mock_sleep(...duration, ...tolerance)` on all flows (`core.rs:17-21,48-52,92-96,160-164,215-219`); absent.
- **Typed DTOs & validation.** `DummyConnectorPaymentRequest`/`RefundRequest` with masked `Secret`/`CardNumber`, `Currency`, `PaymentId` types (`types.rs:114-121,182-215,370-374`); C++ generic JSON (`cppm:136-140,236-240`).
- **Flow instrumentation / metrics / API lock actions.** `#[instrument(flow=...)]` and `LockAction::NotApplicable` on every route (`dummy_connector.rs:17-34,39-60,65-82,86-103,108-127,131-148`); absent.
- **Error mapping.** `DummyConnectorErrors` variants (MissingRequiredField, RefundNotFound, RefundAmountExceedsPaymentAmount, PaymentNotSuccessful, InternalServerError) in `errors.rs`; C++ emits only `EMPTY_REQUEST`/`INVALID_JSON`/`NOT_FOUND` (`cppm:47,95,133,188,233,285,291`).
- **v2 surface divergence.** Upstream v2 exposes only POST `/payment` (`app.rs:890-904`); C++ installs all six v1 routes at the same prefix regardless of version (`cppm:301-367`).
