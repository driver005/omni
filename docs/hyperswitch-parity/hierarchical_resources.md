## Shared contract requests
Framework/shared items that cannot be delivered by edits to this module's exclusive files; local workarounds are in place and do not change route-observable behavior.

1. **Structured `ApiErrorResponse` + `server_wrap` + per-op `Flow` + `LockAction`**: local auth is a flat `authorize_route` (`.cppm:1248-1261`) and errors use `core::error::AppError` (`{"error":...,"message":...}`). Request shared support for upstream `ApiErrorResponse` envelope, `api::server_wrap`, `Flow::HierarchicalResources*`, `LockAction::NotApplicable` in `app/auth`, `core/error`, `app/services`. Workaround: flat auth + `AppError` + `metrics().record_flow` (`.cppm:191-192,252-253,310-311,375-376`).
2. **Real OpenSSL X.509/EC P-256**: request a shared crypto module exposing `X509::from_der`, `EcGroup/EcKey/X509Req`, public-key-DER comparison and CN OID extraction (`core:605-628,685-726`). Workaround: local PEM/DER/CN substitutes (`.cppm:866-972`) with identical wire/error shapes.
3. **Key-manager `transfer_key_to_key_manager` + encrypted `MerchantKeyStore`**: request in `app/keystore`/`app/services`. Workaround: repository-backed `key_store().get/put` AES-256 labels (`.cppm:838-864`).
4. **Account-entity `apple_pay_certificates` / `apple_pay_certificates_encrypted` fields + `RequestorHierarchicalResourceUpdate`**: request in `app/store` domain records + `app/model`. Workaround: `config_store().put` + `events().publish` + link record (`.cppm:644-676`).
